# Security policy

## Reporting a vulnerability
Please report it privately: on GitHub, open **Security → Report a vulnerability** in this repository. Do not open a
public issue.

Include the affected package and version, the steps to reproduce, and the impact you expect. You will get a first
answer within 7 days; a fix is released as a new version on npm and credited in the changelog unless you ask
otherwise.

## Supported versions
Before 1.0 only the latest published version receives security fixes.
