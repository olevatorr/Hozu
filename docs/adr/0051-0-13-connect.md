# ADR 0051 — 0.13: the origins browser-run effects call (`feature({ connect })`)

- **Status:** accepted (owner, 2026-10-03: option A, `{ env }` entries, a warning rather than an error).
- **Problem:** the default CSP is `connect-src 'self'`, the right default. But 0.11's `'browser'` and `'either'`
  effects call other origins from the browser (ADR 0049), and the CSP blocks them on adapter-node and the edge.
  - Nothing said so before the page failed: happy-dom runs no CSP, and a static export sends no CSP header.
  - It was found in `examples/playground` through `hozu browse`.
  - The only fix was `app({ csp: { connect } })`, which nothing pointed to.

## Options
| | Option | For | Against |
|---|---|---|---|
| **A** | **`feature({ connect })` next to `fetch`** | Explicit; written together with fetch.ts; Hozu adds the origins to CSP; tools can list them | One more field; URLs from env need their own form |
| B | Documentation only (`app({ csp })`) | No change | Keeps failing silently in the browser |
| C | `connect-src https:` for apps with fetch.ts | No work for authors | Turns the protection off |

## Decision
- **The field:** `feature({ fetch, connect: ['https://api.github.com', { env: 'API_URL' }] })`.
  - **An origin entry** is an http(s) origin with no path.
  - **An `{ env }` entry** names a public env variable holding a URL; its origin is read at startup.
  - The IR records `FeatureIR.connect: ({ origin } | { env })[]`.
- **The handler:**
  - adds every feature's origins to `connect-src`, together with `app({ csp: { connect } })`;
  - leaves out an unset env variable;
  - refuses to start when the variable holds something that is not a URL.
- **HZ083 `undeclared-connect` (warning):** an absolute URL written in fetch.ts whose origin `connect` does not list.
  The fix is the `connect` line with the origin added. URLs built from env are not visible to it; `hozu browse`
  reports a blocked call at run time.
- **HZ081 (error)** also covers:
  - an entry that is not an origin;
  - an `{ env }` naming a public env variable the project does not declare.
- **A warning, not an error:** apps that already allow the origins through `app({ csp })` keep working.
- **Migration:** 0.12 → 0.13 rewrites nothing. The IR gains `connect: []`, which the step's normalisation adds
  before comparing.
- **Static export** is unchanged: static hosts send no CSP header.

## Not done
- No `connect` in `hozu map` or `inspect` beyond the IR. A later release may list it.
