# ADR 0075 — 0.26.2: a deploy that cannot work says why, before and when it fails

- **Status:** accepted (owner, 2026-10-09: "Ok都照你建議").
- **Evidence:** round 6 of trial 0025 (admin and storefront on 0.26.1). Both apps read MySQL through `mysql2` in
  their TypeScript resolvers; `hozu build --target workers | vercel` failed for both with esbuild's raw output ("Could
  not resolve "net"", 5 of 25 errors shown, `--json` code `usage`), and the partial folder it left refused the retry.
- **Judged as before:** whose problem, which principle. The failure itself is right (a Worker or an Edge Function has
  no TCP socket for `mysql2`); the way it failed breaks principle 7 (a diagnostic names its place, cause and fix).

## Accepted
| # | Ask (source) | Decision |
|---|---|---|
| A1 | Say which file pulls Node in, and what to do (both) | The bundle records every Node built-in an import asks for and the chain from the app file that led there. The build stops with `build` (not `usage`): `server/db.ts → mysql2 → net, tls`, and the ways out: `--target node`, a database driver over HTTP, or `remote()` for those effects |
| A2 | A failed build leaves a partial folder that refuses the retry (both) | The output is removed when the build fails; a folder holding only an earlier partial build counts as this target's output |
| A3 | Know before choosing a platform (store) | `hozu build` without `--target` says per target whether it can serve this app, with the chain when it cannot (`@hozu/bundle` installed) |
| A4 | `--target node` does not mention the Go service (admin) | The services the app reaches through `remote()` are listed under "the platform needs" (deploy them too), and their folders go in `.dockerignore` |
| A5 | `.env` points the database at 127.0.0.1, which a container cannot reach (store) | `--target node` names each env value on a loopback host: inside a container that is the container |
| A6 | A covering element named only by its first class (admin) | The nearest dialog's accessible name comes first: `<div …> in the dialog "Create a discount"` |
| A7 | `press` does not show where focus went (store) | The step says `focused <input name="q">` when focus moved |
| A8 | `.vercel/` is not ignored (admin) | `create-hozu`'s `.gitignore` lists it |
| A9 | The site's code block says "Copy" on Chinese pages | The client module reads the page's `lang` |

## Declined
| Ask | Why not |
|---|---|
| A global toast store (admin, third time) | No global mutable client store (out of scope); the recipe "A notice after saving" stays |
| `app(({ env }) => …)`, more machines per feature, kit components taking data objects (store) | Unchanged reasons (ADR 0069 C, ADR 0070 B4); 0.26's keys removed the reason for a second machine |
| Enabling Cloudflare's `nodejs_compat` so Node modules bundle anyway | A second runtime contract to keep and test; HTTP drivers and `remote()` are the supported ways. Revisit with evidence |
