# ADR 0071 — 0.24: judge the asks by the framework, and stop guessing sections

- **Status:** accepted (owner, 2026-10-08: "思考框架和理性再開始提案，不是他們說什麼就什麼，有的可能是本身就不合邏輯", then
  "照建議，開0.24.0做完發佈").
- **Evidence:** the 0.23 retest of the storefront and the admin (with its Go service). Both upgraded with no source
  change; the storefront deleted 103 more lines than it added; the two apps revalidated each other for the first time.
  Each ask below was judged by what it really is, whose responsibility it is, and the principle it touches.

## A. Accepted
| # | Ask | Decision |
|---|---|---|
| A1 | The menu lost its mark on `/orders?status=open`, and "Back to editor" was marked current (admin); the next-page link was marked (0.22) | **Revert the guess.** 0.22 inferred sections from URL prefixes and 0.23 narrowed the guess; every rule misfires somewhere, because what a section is belongs to the app. The framework marks only the address shown (`aria-current="page"`, canonical URLs compared). A view's render gets `current(route)`, true on that route's pages (any params, any search), resolved by declaration identity (principle 3) into a guard on the new `route` reference: `'aria-current': current(orders) \|\| current(orderDetail)`. `aria-current` false writes no attribute, so `aria-[current]:` styles only marked links |
| A2 | `hozu get --select` refused `nav a[aria-current]` (store) | Descendant and child combinators |
| A3 | `hozu call` on an endpoint with `--write` did not show what it invalidated (store) | It prints the tags, as for a mutation |
| A4 | A pre-0.23 contract was reported as "every effect is missing" (admin) | HZ093 says the contract is in the older format: run `hozu gen` |
| A5 | The migrate summary is one long line (store) | Bullets |
| A6 | `hozu browse` shows full error messages, unlike production (admin) | Kept on purpose (tools debug); a line says what production shows |
| A7 | Untitled enums became one Go type per field, ~30 type errors (admin) | `hozu gen` notes equal untitled enums and suggests `.meta({ title })`; no merge by shape (ADR 0068 rejected naming by shape: equal members are not equal meaning) |
| A8 | A cached query without tags could not be revalidated by the other app (store, its own omission) | Docs: every query another app's writes change needs a tag. No diagnostic: time-based freshness without tags is a legitimate choice, and a warning would fire on all of them |
| A9 | A native post that hit a Go error answered a 500 page (admin) | Docs: an expected failure (a row gone) is a declared error, handled in `failed` with and without JS; `Unexpected` is a server fault and 500 is its right status |

## B. Declined
| Ask | Why not |
|---|---|
| `{ allow }` narrowing the fields its predicate checks (`session.customer`) | The guest session holding `customer: null` is the app's model; flowing a recorded predicate into resolver types is fragile and saves one explicit line |
| A diagnostic for cached queries without tags | See A8: legitimate time-based freshness would all be flagged |
| A no-JS fallback for machine-controlled dialogs (search parameter) | Dialog openness is UI state; the native `commandfor` dialog already works without JS (documented); moving it into the URL makes two ways for one thing |
| Merging equal enums automatically | See A7 |
| 308 to the canonical URL for any search | It would drop tracking parameters; `<link rel="canonical">` already serves search engines |
| `browse` defaulting to production errors | See A6 |
| More than one machine per feature, parts across features, `app()` reading env | Unchanged reasons (ADR 0069 C, ADR 0070 B4) |
