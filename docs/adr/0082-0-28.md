# ADR 0082 — 0.28: what an engineer and a non-engineer met first

- **Status:** accepted (owner, 2026-10-10: "請你直接做到完，都以你建議為主").
- **Evidence:** trial 0026 (ADR 0081, `docs/trials/0026-roles.md`): both roles shipped a small app on 0.27.0 with no
  framework rule worked around; the friction was in the scaffold, the guide and the deploy.
- **No API change.** `hozu migrate` 0.27 → 0.28 rewrites nothing.

## Accepted
| # | Ask (trial 0026 #) | Decision |
|---|---|---|
| A1 | The scaffold's sign-in refuses Chinese names (1) | `hozu add feature … --with auth` and the notes examples accept 1–20 letters of any script (`\p{L}`, the `u` flag); the browser's JSON Schema check compiles a pattern with Unicode semantics, falling back for a pattern written without them |
| A2 | No demo-grade store (2) | Recipe "A JSON file for a demo" (one process, a volume, backups); the data topic points at it |
| A3 | A confirm needs JavaScript unless you know `details` (3) | Recipe "Confirm before deleting, without JavaScript" |
| A4 | The image carries the app's data folder (4) | The generated ignore file adds the entries of the app's `.gitignore` |
| A5 | `docker run` with the development `.env` and no volume (5) | `next:` passes `production.env` and a named volume for each `.gitignore`d folder the app has |
| A6 | `site.url` on localhost unnoticed (6) | Listed under "the platform needs" unless `site.url` comes from env |
| A7 | A server env with a default listed as required (7) | Only variables without a default are listed as required; the others are named as "with a default" |
| A8 | HZ016 offers only a contract when `??` / `?:` alone decides (8) | The cause names the operator and the fix offers the plain copy first (`onlyOperators` in `contracts/mechanical.ts`) |
| A9 | Screenshots of the viewport only, no way to scroll (9) | `--screenshot` captures the whole page (capped at 8 000 px); the step `scroll bottom|top|"<text>"` |
| A10 | `--js both` shares one server state (10) | Said in `--help` and the testing topic |
| A11 | The typed server env inside a feature (11) | The env topic shows `Env extends { DATA_FILE: string }` on the feature's resolvers function |
| A12 | `part`, `current`, `ui.format.date`, keys without an id (12) | One line each in the views topic |
| A13 | `add feature --page /` leaves the replaced page's views unused (13) | The command lists them under `todo` (removing files stays the person's call) |
| A14 | A setting one person edits (14, modified) | Recipe "One person may change this": a role in the session and `access: { allow }`; a typed name is not identity |

## From the review before the tag
- A7 read JSON Schema `required`, but zod's output keeps a defaulted field there: required is now "in `required`
  and without a `default`", as `hozu env` already counted it. The cart example's `STOCK_LIMIT` (default 10) is no
  longer listed as required.
- The confirm recipe's form carries the id in a hidden field and reads it with `ui.dom.form('id')`: a payload read
  from the row needs JavaScript (HZ036).
- `production.env` is in the generated ignore file; `--env-file` is printed only when the app has secrets to pass;
  volumes skip dot and tool folders, normalise `data/*`, and are named `<image>-<folder>` so two apps do not share one.
- The name rule also accepts the middle dots used in Taiwan's indigenous and transliterated names (`·`, `・`, `‧`).
- `scroll` joins the steps a `;` splits, skips script and hidden text; the help says the screenshot is the whole page.
- HZ016's plain-copy hint is not offered when the `?:` condition itself computes.
- The notes-go Go contract is regenerated (its sign-in input schema changed).

## Declined
| Ask | Why not |
|---|---|
| `hozu get` inside the production container (15) | The image is production (`--omit=dev`); check from outside with curl or `hozu get --build` |
| More than one machine per feature (16) | ADR 0069 C |
| Redirect `/?show=all` to `/` (17, investigated) | A page's canonical link already drops search defaults (`pathOf` in `render.ts`), and the page cache is keyed by that URL: search engines see one page. A redirect would add a round trip to links people share |
