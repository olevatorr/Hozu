# ADR 0084 — 0.30: what the Mori back office met

- **Status:** accepted (owner, 2026-10-10: "請你直接做到完，都以你建議為主"; "請繼續").
- **Evidence:** the Mori back office rebuilt on 0.28 (ADR 0080 B). It has 43 routes for two roles, 51 contracts,
  about 365 tool calls, and the frictions C1–C23 in `cms/PROGRESS.md`. Upgrading the Mori public site to 0.29 also
  showed that `hozu browse` could not load its images. Each item was reproduced on the 0.29 source before it was
  judged.
- **No API change.** `hozu migrate` 0.29 → 0.30 rewrites nothing.

## Accepted
| # | Ask | Decision |
|---|---|---|
| A1 | C2: a staff member saw admin links, and no diagnostic said why | `(l.admin ? isAdmin : true) ? link : null` left the outer `?:` as JavaScript, because its test was a conditional and not a reference. The inner `?:` returned the reference itself, a proxy, which JavaScript reads as true, so the link was always kept. `@hozu/transform` now lowers a conditional whose branch is a reference, even when its test is a plain value, so the outer test sees a reference. The same holds when the result is first kept in a `const` |
| A2 | C15: `hozu check` crashed with `Cannot read properties of undefined (reading '_zod')` | A schema that the adapter cannot convert is HZ014 at the declaration that uses it (`/features/f/events/Bad/payload`). The cause names the likely mistake (an object field that is `undefined`, such as a value read from a declaration) and does not stop the build |
| A3 | Images from the Go API were missing in `hozu browse` (Mori public site) | Chrome's Local Network Access treated the page that browse serves (an intercepted `http://localhost`) as public, and blocked loopback requests (`LocalNetworkAccessPermissionDenied`). Browse starts Chrome with `LocalNetworkAccessChecks` disabled, which matches what a page served from localhost gets |
| A4 | C6: `hozu browse` could not fill a file input | The step `upload <label>=<file>[,<file>]` sets the input's files (`DOM.setFileInputFiles`), so its `change` handler runs. Without JavaScript the step says a file reaches the server only through JavaScript |
| A5 | C9, C19: "2 matched; used the first" gave no hint; `in "<text>"` ignored `details` and `article` | The note lists where the matches are (`in "Milk Delete", in "Bread Delete"; add one with in "<text>"`). `in` also scopes to `details` and `article` |
| A6 | C3, C5, C20, C23 | Recipes cover uploading files (`ui.dom.files`, file refs, `file(token)` in the resolver, and that a native post sends names only), a checkbox bound to context (it must send its own change), and showing `Invalid` (`message` for one alert, `fields` per input) |

## From the review before the tag
- A conditional that is now a reference also reaches checks it skipped before: passed to a plain helper, a global,
  `typeof` or an `if`, `FLAG ? ctx.x : y` is reported (HZ059 / HZ047) even when `FLAG` is a constant false. The
  migrate note and the CHANGELOG say so.
- The places a "matched" note names are the scopes `in "<text>"` accepts, so the hint always works.
- A route `search` schema that cannot be converted is reported once, not again at every link to the route.
- Without JavaScript, `upload` still checks the label and the file before saying it needs JavaScript.
- Disabling Local Network Access in browse also hides a deployed public page that loads from localhost; that page is
  misconfigured anyway, and the production browser reports it.
- B2 (one CPU-throttled run) read 41.6 ms in one gate and 54.3 ms in the next, with no runtime-client change between
  them: recorded as unstable (ADR 0083), not a regression.

## Declined
| Ask | Why not |
|---|---|
| C23 as a runtime change: re-apply `checked` after every event | A control bound to context but read only on submit would lose what the person typed whenever another event ran. A bound control that the person can change must send its change (recipe) |
| C5: native multipart uploads | A file needs a token from the upload endpoint before the mutation runs; a native post has no such step. The recipe says so, and `hozu get --forms` keeps file inputs out, because posting them as text would mislead |
| C1: install `@hozu/variants` in every scaffold | Most apps have no kit. `hozu add kit` prints the install command |
| C7: a template string in `failed` asks for a contract | 0.28's HZ016 already names the operator and offers the plain copy |
| C8, C11, C16, C17, C18 | One canonical form or the existing way: children are passed when a component declares them; a button's value is a literal in the payload; an enum input comes from an enum context field; a `fn()` returns the value needed (ADR 0083 A8); a recursive editor is a client component |
| C12, C21: arrays of references or `c ? [..] : [..]` as props; C14: a query inside a closed dialog runs on the server | Recorded for the post-1.0 design of props and lazy regions |
