# ADR 0078 — 0.26.5: a printed fix runs the version it names

- **Status:** accepted (owner, 2026-10-09: "Ok都照你建議").
- **Evidence:** round 9 of trial 0025 (admin and storefront, 0.26.3 → 0.26.4). Both upgraded by the printed lines
  alone; `hozu check` stopped on the mismatch with two lines and exit 2, `migrate` listed `done:` and refreshed the
  guide, and the storefront kept `/` on the search field inside its menu `<dialog>`. Both: no regression; the store:
  "nothing currently blocks normal development".

## Accepted
| # | Ask (source) | Decision |
|---|---|---|
| A1 | The mismatch fix `npx hozu migrate` runs the project's installed, older CLI and does nothing (both) | The fix names the version: `npx -p @hozu/cli@<cli> hozu migrate` |
| A2 | Focus notes name fields but not buttons and links: `focused <button>` (admin) | A link, button or summary is named by its text when it has no `aria-label` |
| A3 | Without JS, a key no control has says `nothing is focused` (admin) | `no control has <key>`, as with JS |
| A4 | `--target node` prints `wrote ../../…` and an absolute `docker build -f` in one output (store) | Every printed path follows one rule: relative inside the current folder, absolute outside it, quoted when needed |

## Investigated, not changed
- **A shrinking keyed list reported as a flash (admin):** reproduced with five rows becoming `[1, 9]`. Row 9 is new and
  takes the place of the removed row 2, so it fades in as an added row (ADR 0067), and its unchanged text visibly
  blinks. The report is accurate. The app's fix is stable keys (a fixed set of steps). Whether a removal and an
  addition at one place should count as a swap, which does not fade, is a question for 0.27.

## Declined
| Ask | Why not |
|---|---|
| `--update-ignore` to write the missing lines into a kept `.dockerignore` (admin) | The tool names the exact lines; editing the person's file is a step beyond reporting |
| A version tag on the image name (store) | A tag per build leaves an image per build; the project name is the usual name, and two projects with one name is the person's choice |
