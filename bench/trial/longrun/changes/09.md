# Change request 09 for the notes app

The app in this directory already implements the notes app. Everything it does today must keep working, with and
without JavaScript, unless this request changes it. Change the following.

## The list moves to `/notes`
- The list page (everything that was on `/`) moves to `/notes`, including its URL filters (`/notes?tag=work`,
  `/notes?q=milk`).
- `/` now only redirects: to `/notes` when a user is signed in, to `/login` otherwise. `/notes` redirects to
  `/login` when nobody is signed in.
- After signing in the browser ends up on `/notes`. After signing out it ends up on `/login`, as before.
- Every link and form that led to `/` now leads to `/notes` (for example `All notes` and the tag links).
