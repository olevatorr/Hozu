# Change request 11 for the notes app

The app in this directory already implements the notes app. Everything it does today must keep working, with and
without JavaScript, unless this request changes it. Change the following.

## Load more
- The list page shows at most 5 notes at first, in the usual order (pinned first, then newest first).
- The page shows the text `Showing <n> of <m>`, where `<m>` is the number of notes the URL filters (`?tag=`, `?q=`)
  select and `<n>` the number currently listed (for example `Showing 5 of 7`, or `Showing 0 of 0`).
- While more notes exist, a control `Load more` (a button or a link) lists the next 5 below the ones shown. When all
  are listed, `Load more` is not shown.
- Typing in `Search` with JavaScript filters the notes currently listed.
- `Notes: <count>` still shows the total number of the user's notes that are not archived.
- `Load more` also works with JavaScript disabled.
