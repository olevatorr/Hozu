# Change request 10 for the notes app

The app in this directory already implements the notes app. Everything it does today must keep working, with and
without JavaScript, unless this request changes it. Change the following.

## Undo a delete
- After a note is deleted, the list page shows, in an element with `role="status"`, the text
  `Deleted "<title>"` and a button `Undo`.
- `Undo` puts the note back exactly as it was: the same title, place in the list, pin, tags and `Added` date. The
  message then disappears.
- Only the most recent delete can be undone. The message stays (also across a reload) until `Undo`, until the user's
  notes change again (add, delete, edit, pin, archive, restore), or until the user signs out.
- This is stored on the server per user; other users are not affected.
- Undo also works with JavaScript disabled.
