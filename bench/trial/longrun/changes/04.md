# Change request 04 for the notes app

The app in this directory already implements the notes app. Everything it does today must keep working, with and
without JavaScript, unless this request changes it. Change the following.

## A note's text is its title
The product now calls a note's text its **title**. Rename it end to end: in the UI, in the data the server keeps,
and in the code.
- The add input's accessible label is `Title` instead of `New note` (the button stays `Add`).
- The duplicate message is `You already have a note with this title` instead of `You already have this note`.
- Everything else about adding (trimming, 1–60 characters, `maxlength="60"`, the server-side duplicate check, the
  alert role) is unchanged.
