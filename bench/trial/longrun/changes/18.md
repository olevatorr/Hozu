# Change request 18 for the notes app

The app in this directory already implements the notes app. Everything it does today must keep working, with and
without JavaScript, unless this request changes it. Change the following.

## German
- The app gets a second language, German. English stays the default, and the English pages keep their URLs.
- `/login` and the list page get a control (a link or a button) with the text `Deutsch` while the page is in English
  and `English` while it is in German. It switches the language. The choice persists in that browser across
  reloads, signing in and signing out; it is not stored in the account. Like every cookie, a cookie that holds it
  must be `HttpOnly`.
- The `<html>` element has `lang="en"` or `lang="de"`.
- In German, at least these texts are exactly:

| English | German |
|---|---|
| `Sign in` (heading and button) | `Anmelden` |
| `Notes` (heading) | `Notizen` |
| `Signed in as <name>` | `Angemeldet als <name>` |
| `Sign out` | `Abmelden` |
| `Notes: <count>` | `Notizen: <count>` |
| `Title` (label) | `Titel` |
| `Add` | `Hinzufügen` |
| `Delete` | `Löschen` |
| `Search` (label) | `Suche` |
| `You already have a note with this title` | `Du hast bereits eine Notiz mit diesem Titel` |

- Note titles and user names are never translated. Other texts may be translated or stay in English.
- Switching the language also works with JavaScript disabled.
