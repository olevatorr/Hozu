# Change request 02 for the notes app

The app in this directory already implements the notes app. Everything it does today must keep working, with and
without JavaScript, unless this request changes it. Change the following.

## Shorter notes
- A note is now at most 60 characters (after trimming), not 100.
- The browser blocks longer input: the `New note` input has `maxlength="60"`.
- The **server** rejects a longer note (for example one posted by a script) and the page shows the text
  `Use at most 60 characters` in an element with `role="alert"`. Nothing is added.
- Existing notes are unaffected.
