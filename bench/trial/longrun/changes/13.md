# Change request 13 for the notes app

The app in this directory already implements the notes app. Everything it does today must keep working, with and
without JavaScript, unless this request changes it. Change the following.

## Bulk actions
- Each note's `<li>` on the list page gets a checkbox with the accessible label `Select <title>` (for example
  `Select Buy milk`).
- Two buttons act on the checked notes: `Delete selected` deletes them and `Archive selected` archives them. With no
  note checked they do nothing.
- With JavaScript, the text `Selected: <n>` shows how many notes are checked and updates as boxes are checked.
- A bulk delete cannot be undone; it clears any `Undo` message.
- `Delete selected` and `Archive selected` also work with JavaScript disabled.
