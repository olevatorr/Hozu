# Change request 03 for the notes app

The app in this directory already implements the notes app. Everything it does today must keep working, with and
without JavaScript, unless this request changes it. Change the following.

## When a note was added
- Every note records the moment it was created, on the server.
- Each note's `<li>` contains a `<time>` element whose `datetime` attribute is that moment in ISO 8601 UTC (for
  example `2026-09-29T08:15:00.000Z`), and the `<li>` shows the text `Added <YYYY-MM-DD>` (the UTC date), for
  example `Added 2026-09-29`.
