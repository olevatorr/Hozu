# Change request 12 for the notes app

The app in this directory already implements the notes app. Everything it does today must keep working, with and
without JavaScript, unless this request changes it. Change the following.

## Instant add
- With JavaScript, after `Add` the new note appears first in the list at once, before the server has answered, and
  its `<li>` contains the text `saving` until the server has accepted it. Then `saving` disappears and the note is
  an ordinary note.
- If the server rejects the note (for example a duplicate), the note disappears from the list again and the page
  shows the server's message in an element with `role="alert"`, as before.
- Clicking `Add` twice quickly must still add the note only once.
- Without JavaScript adding works as before.
