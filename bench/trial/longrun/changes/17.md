# Change request 17 for the notes app

The app in this directory already implements the notes app. Everything it does today must keep working, with and
without JavaScript, unless this request changes it. Change the following.

## Delete an account
- The list page gets a link `Delete account` to a new page `/account/delete` (redirecting to `/login` when nobody is
  signed in) with an `<h1>` with the text `Delete account` and a button `Delete my account and notes`.
- That button deletes all of the user's notes, archived ones included, and signs the user out. The browser ends up on
  `/login`, which then shows the text `Account deleted`.
- Notes the user had shared disappear for the users they were shared with. Notes others shared with the user are not
  affected for their owners.
- Signing in again with the same name starts with no notes, as for a new name. Until then, the admin table no longer
  lists the user.
- Deleting an account also works with JavaScript disabled.
