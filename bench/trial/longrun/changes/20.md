# Change request 20 for the notes app

The app in this directory already implements the notes app. Everything it does today must keep working, with and
without JavaScript, unless this request changes it. Change the following.

## Remove tags
Tags are not used, so remove them completely.
- The `Tags` input, the `#<tag>` links, the `Tagged <tag>` text and the `All notes` link are removed.
- `?tag=` in the URL is ignored: `/notes?tag=work` shows the list as if it were absent.
- The export (`/api/export`) no longer has a `tags` key; each note has exactly `title`, `pinned`, `archived` and
  `createdAt`.
- Remove the code and data for tags too, not only the UI.
