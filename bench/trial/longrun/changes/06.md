# Change request 06 for the notes app

The app in this directory already implements the notes app. Everything it does today must keep working, with and
without JavaScript, unless this request changes it. Change the following.

## Tags
- The add form gets a second text input with the accessible label `Tags`. It is optional and takes a
  comma-separated list, for example `work, home`.
- Tags are trimmed and lowercased; empty entries and repeats are dropped. A tag is 1–20 characters of letters,
  digits or `-`. The **server** rejects a note with any other tag, showing `Tags use letters, digits and -` in an
  element with `role="alert"`, and adds nothing.
- Each tag of a note is shown in its `<li>` as a link with the text `#<tag>` to the list page with `?tag=<tag>` in
  the URL (for example `/?tag=work`).
- With `?tag=<tag>` in the URL the list shows only the notes with that tag, and the page shows the text
  `Tagged <tag>` and a link `All notes` back to the unfiltered list. `Notes: <count>` still shows the total number of
  the user's notes. The URL filter works on first load and with JavaScript disabled.
- Editing (the `Edit` button) changes only the title; tags cannot be changed after adding.
- The seeded notes have no tags.
