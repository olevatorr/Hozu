# Change request 15 for the notes app

The app in this directory already implements the notes app. Everything it does today must keep working, with and
without JavaScript, unless this request changes it. Change the following.

## Share a note with another user
- Each note's `<li>` on the list page gets a text input with the accessible label `Share with` and a button `Share`.
  Sharing with a valid name (2–20 letters) that is not your own gives that user read access to the note. Sharing
  with your own name shows `You cannot share with yourself` in an element with `role="alert"`.
- For each user a note is shared with, the owner's `<li>` shows the text `shared with <name>` and a button
  `Unshare <name>`, which removes that user's access.
- A user with shared notes sees, on their list page, an `<h2>` with the text `Shared with me` followed by a `<ul>` of
  those notes. Each `<li>` there contains the title and the text `from <owner>`, and no buttons or inputs. When
  nothing is shared with the user, the heading and that list are absent.
- A shared note always shows its current title. When the owner deletes or archives it, it disappears for the users
  it was shared with; restoring it shares it again.
- Shared notes are not the recipient's own: they are not in `Notes: <count>`, not in the recipient's duplicate check,
  search, tag filter or `Load more`, and the recipient cannot change them (the **server** refuses).
- **The HTML sent to a user contains only their own notes and the notes shared with them.**
- Sharing and unsharing also work with JavaScript disabled.
