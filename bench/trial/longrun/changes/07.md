# Change request 07 for the notes app

The app in this directory already implements the notes app. Everything it does today must keep working, with and
without JavaScript, unless this request changes it. Change the following.

## Archive
- Each note's `<li>` on the list page gets a button `Archive`. An archived note leaves the list.
- A new page `/archive`, reached by a link `Archived notes` on the list page:
  - when nobody is signed in, the request is redirected to `/login`;
  - an `<h1>` with the text `Archive`;
  - the user's archived notes as a `<ul>`, newest first; each `<li>` contains the title and a button `Restore`, and
    nothing else that acts on the note;
  - with no archived notes, the text `No archived notes` instead of the list.
- **Archived notes are read-only:** they cannot be edited, pinned, deleted or archived again, and the **server**
  refuses those actions for an archived note.
- `Restore` moves the note back to the list page, where it keeps its title, pin, tags and `Added` date.
- `Notes: <count>` counts only notes that are not archived. A title that an archived note has is still a duplicate
  when adding or editing.
- Archiving and restoring also work with JavaScript disabled.
