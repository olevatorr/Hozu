# Change request 05 for the notes app

The app in this directory already implements the notes app. Everything it does today must keep working, with and
without JavaScript, unless this request changes it. Change the following.

## Edit a note in place
- Each note's `<li>` gets a button `Edit`.
- Editing a note shows, in that note's `<li>`, a text input with the accessible label `Edit title` holding the current
  title, a button `Save` and a button `Cancel`. Only one note is edited at a time.
- `Save` applies the rules of adding: the title is trimmed, 1–60 characters (`maxlength="60"` on the input), and the
  **server** rejects a title that another of the user's notes already has (case-insensitive, after trimming; the note
  itself does not count). A duplicate shows `You already have a note with this title` in an element with
  `role="alert"` and leaves the note unchanged.
- After a successful save the `<li>` shows the new title and no edit input. The note keeps its place in the list,
  its pin and its `Added` date.
- `Cancel` leaves the note unchanged and closes the edit.
- Editing also works with JavaScript disabled.
