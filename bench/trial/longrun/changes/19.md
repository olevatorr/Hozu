# Change request 19 for the notes app

The app in this directory already implements the notes app. Everything it does today must keep working, with and
without JavaScript, unless this request changes it. Change the following.

## Export as JSON
- `GET /api/export` returns the signed-in user's own notes as JSON, with status 200 and a `Content-Type` of
  `application/json`:

```json
{ "user": "ada", "notes": [{ "title": "Buy milk", "pinned": false, "archived": false, "tags": [], "createdAt": "2026-01-15T09:00:00.000Z" }] }
```

- `notes` lists every note the user owns, archived ones included and shared-with-me ones excluded, in the list
  page's order (pinned first, then newest first), with exactly these five keys. `createdAt` is the moment from the
  `Added` date, in ISO 8601 UTC.
- When nobody is signed in it returns status 401.
- The list page gets a link `Export` to `/api/export`.
