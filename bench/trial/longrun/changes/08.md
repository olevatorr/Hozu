# Change request 08 for the notes app

The app in this directory already implements the notes app. Everything it does today must keep working, with and
without JavaScript, unless this request changes it. Change the following.

## Search in the URL
- The search text is also kept in the URL as `?q=<text>`. Loading the list page with `?q=milk` renders the list
  already filtered (case-insensitive, as before) with `milk` in the `Search` input, also with JavaScript disabled.
- A submit button `Search` next to the `Search` input submits the search. Without JavaScript this is how a user
  searches.
- With JavaScript, typing still filters the list immediately (as before); the URL does not have to change while
  typing.
- `?q=` and `?tag=` combine: both filters apply.
- `No notes match` is shown when the filters leave no note, and `Notes: <count>` still shows the total.
