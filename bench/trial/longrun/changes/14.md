# Change request 14 for the notes app

The app in this directory already implements the notes app. Everything it does today must keep working, with and
without JavaScript, unless this request changes it. Change the following.

## Limit how fast notes are added
- A user can add at most 10 notes within any 60 seconds.
- The **server** rejects an add beyond that and the page shows `Too many notes, try again in a minute` in an element
  with `role="alert"`. Nothing is added.
- Only notes that were actually added count; rejected adds (duplicates, invalid input, this limit), edits, restores
  and undos do not. The limit is per user.
