# Change request 22 for the notes app

The app in this directory already implements the notes app. Everything it does today must keep working, with and
without JavaScript, unless this request changes it. Change the following.

## A page for each note
- Each note has its own page at `/notes/<number>`, where `<number>` is the note's number (for example `/notes/3`).
- On the list page and on `/archive`, each note's title is a link to its page.
- The note page shows:
  - an `<h1>` with the note's current title;
  - the text `No. <number>`, and the text `Added <YYYY-MM-DD>` with a `<time>` element as on the list page;
  - the text `pinned` when the note is pinned, and the text `Archived` when it is archived;
  - a link `Back to notes` to `/notes`.
- When nobody is signed in, `/notes/<number>` redirects to `/login`.
- A user only ever reaches their own notes this way. When the signed-in user has no note with that number (it never
  existed, it was deleted, or `<number>` is not a number at all), the page responds with HTTP status 404 and shows
  the text `Note not found`. Notes shared with the user are not reachable through these pages, and these pages never
  contain other users' notes.
- The note page and the links to it also work with JavaScript disabled.
