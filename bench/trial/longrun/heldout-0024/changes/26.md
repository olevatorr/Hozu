# Change request 26 for the notes app

The app in this directory already implements the notes app. Everything it does today must keep working, with and
without JavaScript, unless this request changes it. Change the following.

## Export: numbers, bodies and CSV
- Each note in `GET /api/export` now has exactly the keys `number`, `title`, `body`, `pinned`, `archived` and
  `createdAt`. `number` is the note's number as a JSON number; `body` is its body as a string (`""` when empty),
  with each line break as `\n`. Everything else about the JSON export is unchanged, and `?format=json` gives the
  same result.
- `GET /api/export?format=csv` returns the same notes in the same order as CSV, with status 200 and a
  `Content-Type` of `text/csv`:
  - the first line is `number,title,body,pinned,archived,createdAt`, then one line per note;
  - `pinned` and `archived` are `true` or `false`, and `createdAt` is as in the JSON export;
  - a value that contains a comma, a double quote or a line break is enclosed in double quotes, and each double quote
    inside it is doubled (for example `"Say ""hi"", Bob"`); other values are not quoted;
  - every line, the last one included, ends with CRLF (`\r\n`). Line breaks inside a body stay `\n`.
- Both formats are downloads: the response has the header `Content-Disposition: attachment;
  filename="notes-<user>.json"` or `attachment; filename="notes-<user>.csv"`.
- Any other `format` gives status 400. When nobody is signed in, every format gives status 401.
- The list page gets a link `Export CSV` to `/api/export?format=csv`, next to `Export`.
