# Change request 21 for the notes app

The app in this directory already implements the notes app. Everything it does today must keep working, with and
without JavaScript, unless this request changes it. Change the following.

## Note numbers
- Every note gets a number that identifies it among its owner's notes: `1` for the user's first note, `2` for the
  next, and so on. Each note's `<li>` on the list page shows the text `No. <number>`, for example `No. 3`.
- Notes that already exist get their numbers now, in the order of their `Added` moment, oldest first. The seeded
  notes are numbered:

| user | note | number |
|---|---|---|
| ada | `Call Bob` | 1 |
| ada | `Buy milk` | 2 |
| bob | `Bob's secret` | 1 |

- A note added later gets the number after the highest one its owner has ever had. A number is never reused:
  deleting a note (also with `Delete selected`) does not free its number.
- A note keeps its number when it is edited, pinned, archived, restored or brought back with `Undo`.
- Numbers are per user: one user's notes do not affect another user's numbers. After an account is deleted, the same
  name starts again at `1`.
- The numbers are stored on the server and shown with and without JavaScript.
