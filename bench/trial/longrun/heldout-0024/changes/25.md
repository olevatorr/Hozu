# Change request 25 for the notes app

The app in this directory already implements the notes app. Everything it does today must keep working, with and
without JavaScript, unless this request changes it. Change the following.

## Shared notes update live
- With JavaScript, the `Shared with me` part of an open list page keeps itself up to date, without a reload: within
  5 seconds of a change by the owner it shows the change. This covers the owner sharing a note with the user,
  unsharing it, renaming it (on the list page or on the note's page), archiving, restoring or deleting it, and
  deleting their account.
- The `Shared with me` heading appears with the first shared note and disappears with the last, as on a fresh load.
- Nothing else on the page changes by itself: what the user is typing, the notes they have checked and an open edit
  stay as they are, and the page is not reloaded.
- Without JavaScript the page shows the current state each time it is loaded, as before.
