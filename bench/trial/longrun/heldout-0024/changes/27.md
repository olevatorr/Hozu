# Change request 27 for the notes app

The app in this directory already implements the notes app. Everything it does today must keep working, with and
without JavaScript, unless this request changes it. Change the following.

## Undo for Delete selected
- `Delete selected` can now be undone, like a single delete. This replaces the rule of change 13 that a bulk delete
  cannot be undone and clears any `Undo` message.
- After `Delete selected`, the list page shows, in the element with `role="status"`, the text `Deleted "<title>"`
  when one note was deleted, or `Deleted <n> notes` when several were, and a button `Undo`.
- `Undo` puts every one of those notes back exactly as it was: title, body, number, place in the list, pin,
  `Added` date and the users it was shared with. The message then disappears.
- As before, only the most recent delete (single or selected) can be undone, and the message stays (also across a
  reload) until `Undo`, until the user's notes change again, or until the user signs out.
- Undoing `Delete selected` also works with JavaScript disabled.
